It also provides deduplication via rapidfuzz so the pipeline can return diverse results.

    **ScoredResult dataclass:**
    ```python
    @dataclass
    class ScoredResult:
        url: str
        title: str
        snippet_text: str          # Best snippet text
        best_sentence: str         # Most relevant sentence within snippet
        composite_score: float     # 0.0-1.0 final score
        score_breakdown: dict      # {"relevance": float, "authority": float, "freshness": float, "position": float}
        source_url: str
        source_type: str           # Inferred from domain (e.g., "documentation", "forum", "news", "blog", "unknown")
        detected_date: Optional[str]  # ISO date string if found, None otherwise
        confidence: float          # From query analyzer
        original_position: int
        is_code: bool
    ```

    **QualityScorer class:**
    - `score(snippet: ExtractedSnippet, ranked: RankedResult, query: AnalyzedQuery) -> ScoredResult`
    - Composite formula with query-type-aware weights:
      - For news: relevance=0.35, authority=0.20, freshness=0.25, position=0.20
      - For code: relevance=0.45, authority=0.25, freshness=0.0, position=0.15 (redistribute freshness to relevance+authority)
      - For general/research/how-to/lookup/comparison: relevance=0.45, authority=0.20, freshness=0.0, position=0.15 (redistribute to relevance)
      - Note: When freshness is None, redistribute its weight proportionally to relevance and authority
    - Position score formula: `max(0.0, 1.0 - (position - 1) * 0.1)` — position 1 = 1.0, position 10 = 0.1, position 11+ = 0.0
    - `infer_source_type(url: str) -> str` — map domains to categories: "documentation" (docs.*, readthedocs), "forum" (stackoverflow, reddit), "news" (reuters, bbc), "repository" (github), "blog" (medium, dev.to), "wiki" (wikipedia), "unknown"

    **deduplicate_results function:**
    - `deduplicate_results(results: List[ScoredResult], threshold: float = 0.85) -> List[ScoredResult]`
    - Use `rapidfuzz.fuzz.token_sort_ratio` for similarity (lazy import pattern per project convention)
    - Compare snippet_text between all pairs; if ratio > threshold * 100, keep the one with higher composite_score
    - O(n^2) is fine — result lists are small (5-10 items max)
    - Fallback: if rapidfuzz not installed, skip dedup and return input unchanged (same pattern as Playwright optional dep)

    **Tests (tests/test_quality_scorer.py):**
    Write tests FIRST per TDD. Cover all behaviors listed above. Use pytest with simple fixtures — no mocking of external services needed since QualityScorer is pure computation.
