AUTHORITY_TIERS = {
    "code": {
        "docs.python.org": 1.0, "docs.rust-lang.org": 1.0, "developer.mozilla.org": 1.0,
        "docs.microsoft.com": 1.0, "stackoverflow.com": 1.0, "github.com": 1.0,

    },
    "research": {
        "arxiv.org": 1.0, "wikipedia.org": 1.0, "scholar.google.com": 0.8,
        "nature.com": 1.0, "sciencedirect.com": 0.8,
        "stackoverflow.com": 0.5, "medium.com": 0.5, "github.com": 0.5,

    },

BLOCKED_DOMAINS = {
    "answers.com", "ask.com", "ehow.com", "brighthub.com",
    "quora.com",  # Often paywalled/login-gated
    "pinterest.com",  # Image-only, no useful text
    "scribd.com",  # Paywall
}

3. **ResultReranker class** with methods:
   - `get_authority_score(url: str, query_type: str) -> float` — Extract domain from URL via `urlparse().netloc.lower().replace("www.", "")`. Check BLOCKED_DOMAINS first (return 0.0). Then check query-type-specific map, then base domain (strip subdomain to last 2 parts). Default 0.5 for unknown. Per Pitfall 6: NEVER return 0.0 for unknown domains.
   - `get_freshness_score(snippet: str, query_type: str) -> Optional[float]` — Per D-09, return None for non-news intents. For news: try `dateutil.parser.parse()` on snippet text to find dates. Compute exponential decay: `score = max(0.0, 1.0 - (days_old / 30))` capped at 0.0-1.0. If no date found, return 0.3 (penalized but not zero). Use `python-dateutil` (already in requirements).
   - `rerank(results: List[dict], query_type: str) -> List[RankedResult]` — Takes list of dicts with keys {url, title, snippet, position}. Computes authority + freshness for each. Sorts by authority_score descending (blocked at bottom). Returns List[RankedResult] with original_position preserved.

IMPORTANT per D-09: Freshness penalty ONLY for news/current-event queries. Code and research intents get freshness_score=None.
IMPORTANT per Pitfall 6: Unknown domains default to 0.5 (Standard), NEVER 0.0.
IMPORTANT per D-10: Blocked domains always score 0.0 and are marked is_blocked=True.
