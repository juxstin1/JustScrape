Key implementation details:

1. **AnalyzedQuery dataclass** (per D-02):
```python
@dataclass
class AnalyzedQuery:
    original: str
    intent: str          # "code"|"research"|"news"|"how-to"|"lookup"|"comparison"|"general"
    confidence: float    # 0.0-1.0
    expanded_queries: List[str]
    sub_queries: List[str]
    entities: List[dict]  # [{text: str, type: str}]
```

2. **QueryAnalyzer class** with methods:
   - `classify_intent(query) -> tuple[str, float]` — per D-01, rules-only. Six compiled regex patterns at module level: `_CODE_PATTERN`, `_NEWS_PATTERN`, `_HOW_TO_PATTERN`, `_RESEARCH_PATTERN`, `_COMPARISON_PATTERN`, `_LOOKUP_PATTERN`. Count matches per pattern, compute confidence as `top_matches / total_matches + 0.3` capped at 1.0. Zero matches -> ("lookup", 0.5). Confidence < 0.7 -> return ("general", confidence) per D-03.
   - `expand_query(query) -> List[str]` — per D-04, aggressive expansion. Hardcoded abbreviation dict (`{"JS": "JavaScript", "TS": "TypeScript", "py": "python", "ML": "machine learning", "AI": "artificial intelligence", "DB": "database", "API": "application programming interface", "CSS": "cascading style sheets", "HTML": "hypertext markup language", "SQL": "structured query language", "k8s": "kubernetes", "tf": "terraform"}`). Term expansion dict for related terms (`{"react hooks": ["react useState useEffect", "react useCallback useMemo"], "docker": ["docker container dockerfile"], "git": ["git commit push pull branch"]}`). Always include original query first.
   - `decompose_query(query) -> List[str]` — per D-05, split ONLY on conjunctions: `r'\s+(?:and|vs\.?|or|compared\s+to)\s+'`. If no split, return `[query]`.
   - `extract_entities(query) -> List[dict]` — per D-06, regex only. Three compiled patterns: `VERSION_PATTERN = r'\bv?\d+\.\d+(?:\.\d+)?\b'`, `LANGUAGE_NAMES` set (python, javascript, typescript, rust, go, java, c\+\+, ruby, php, swift, kotlin, scala, perl, lua, r, julia, elixir, haskell, clojure, dart), `LIBRARY_NAMES` set (numpy, pandas, react, vue, angular, django, flask, fastapi, express, tensorflow, pytorch, scikit-learn, matplotlib, requests, httpx, playwright, docker, kubernetes, redis, postgres, mongodb).
   - `analyze(query) -> AnalyzedQuery` — orchestrate: classify, expand, decompose, extract, return dataclass.

IMPORTANT per D-01: No spacy, no ML imports. Only stdlib + dataclasses.
IMPORTANT: Do NOT add length-based scoring anywhere.
IMPORTANT per research Pitfall P10: Do NOT strip stop words from code queries — "is in", "for loop", "not null" are meaningful Python.
