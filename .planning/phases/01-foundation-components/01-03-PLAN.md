Key implementation details:

1. **ExtractedSnippet dataclass** (per D-13):
```python
@dataclass
class ExtractedSnippet:
    text: str
    chunk_index: int
    score: float           # blended BM25+TF-IDF, 0.0-1.0
    is_code: bool          # True if chunk is a code block per D-15
    source_url: str
    best_sentence: str     # Most relevant sentence within chunk per EXTRACT-04
```

2. **Module-level compiled regex patterns** (per D-12/D-15):
```python
_HEADING_PATTERN = re.compile(r'^#{1,6}\s+.+$', re.MULTILINE)
_CODE_FENCE_PATTERN = re.compile(r'```[\s\S]*?```', re.MULTILINE)
_INDENTED_CODE_PATTERN = re.compile(r'(?:(?:^(?:    |\t).+\n?){2,})', re.MULTILINE)
CHUNK_SIZE_THRESHOLD = 800  # Characters per research recommendation
```

3. **SnippetExtractor class** with methods:

   - `extract_text(html: str, url: str = "") -> str` — Per D-16/EXTRACT-01: Call `trafilatura.extract(html, url=url, favor_precision=True, include_tables=True, include_comments=False, include_formatting=False)`. Return result or empty string if None. NEVER propagate None — always coerce to str. Per Pitfall 4: handle None return gracefully.

   - `chunk_content(text: str) -> List[Tuple[str, bool]]` — Per D-12/EXTRACT-02: (1) Extract code fences first, replace with placeholders (per research Pattern 6). (2) Also detect 4-space/tab indented blocks of 2+ lines as code (per Pitfall 5). (3) Split remaining text on heading patterns (# through ######). (4) For heading-sections > CHUNK_SIZE_THRESHOLD (800 chars), split further on double newlines (paragraph boundaries). (5) Restore code placeholders. (6) Return list of (chunk_text, is_code) tuples. Empty text returns empty list.

   - `score_chunks(query: str, chunks: List[Tuple[str, bool]], intent: str = "general", top_n: int = 3, bm25_weight: float = 0.5) -> List[ExtractedSnippet]` — Per D-14/EXTRACT-03: (1) Tokenize chunks and query with `.lower().split()`. (2) BM25Okapi scoring, normalize by dividing by max (guard max==0). (3) TfidfVectorizer + cosine_similarity scoring. (4) Blend: `bm25_weight * bm25_norm + (1 - bm25_weight) * tfidf_scores`. (5) Per D-15: if intent=="code", add +0.2 boost to chunks where is_code=True (cap at 1.0). (6) Sort descending, return top_n with score > 0.0. (7) For each result, call extract_best_sentence to populate best_sentence field. CRITICAL per Pitfall P2: NO length component in scoring. NO `len(chunk)` bonus.

   - `extract_best_sentence(chunk_text: str, query: str) -> str` — Per EXTRACT-04: Split chunk into sentences (split on `. ` or `.\n` or `? ` or `! `). Use TfidfVectorizer + cosine_similarity to score each sentence against query. Return highest-scoring sentence. If chunk has <= 1 sentence, return the whole chunk. This is sentence-level matching using TF-IDF (NOT neural — neural is Phase 3).

   - `extract_snippets(html: str, query: str, intent: str = "general", url: str = "", top_n: int = 3) -> List[ExtractedSnippet]` — Orchestrate: extract_text -> chunk_content -> score_chunks. Set source_url on all results. Return empty list if extraction produces no text.

IMPORTANT per D-14: BM25 weight = 0.5, TF-IDF weight = 0.5. Expose as parameter for future tuning.
IMPORTANT per Pitfall P2: ZERO length component in scoring. Score = `0.5 * bm25_norm + 0.5 * tfidf_cosine`. Nothing else.
IMPORTANT per Pitfall P3: Normalize BM25 scores by dividing by max. Guard `max == 0`.
IMPORTANT per Pitfall P4: `trafilatura.extract()` can return None. Always coerce: `text = extract(...) or ""`.
IMPORTANT per Pitfall P5: Detect code by both triple-backtick fences AND 4-space/tab indented blocks.
